Аргинин

Зависит от условий. Есть данные: преэклампсия: RR 0.52, тяжёлая 0.23. При условиях: АД/пампинг: слабее цитруллина, контекст.

есть хорошие испытания
Доза3-6 г/сут (часто ЖКТ-побочки)
ПределФормального UL не установлен: данных о токсичности нет.
Эффект черезАД-отклик за часы-дни; преэклампсия: курсы неделями; в спорте эффект непредсказуем.
Кому нужноБеременные с риском преэклампсии, недоношенные (НЭК): по назначению врача. Для спорта лучше L-цитруллин.

Суть

Предшественник оксида азота: для пампинга слабее цитруллина; ниши: преэклампсия, НЭК у недоношенных.

Что говорят исследования

Преэклампсия: RR 0.52, тяжёлая 0.23 (2025, n=2028); уверенность низкаяработает
АД/пампинг: слабее цитруллина, контекстзависит от условий
Некротизирующий энтероколит: профилактический механизм, 3 РКИ (n=285)не доказано

Форма важна

Если аргинин: L-форма, без «технологий». Доза: по цели приёма (преэклампсия / НЭК: по назначению врача)..

L-аргинин, капсулы. Усваивается плохо; для кровотока цитруллин работает лучше.

Мифы

«Мощный пампинг»: биодоступность низкая, цитруллин лучше.

«Больше: лучше»: выше 6 г бьёт по ЖКТ.

«Лечит преэклампсию»: лишь снижает риск.

Осторожно

L-аргинин: прекурсор оксида азота (NO).

Для профилактики преэклампсии: данные есть.

Для некротизирующего энтероколита (НЭК) у недоношенных: Cochrane подтверждает эффективность.

Для оксид азота при стенокардии: Cochrane.

Для давления: умеренное снижение.

Для эректильной дисфункции: ограниченные данные (часто с пикногенолом).

Для гликемического контроля: смешанные данные.

С лекарствами

Антигипертензивныеможет усиливать эффект
Нитратыусиливает вазодилатацию

Из еды

Мясо, птица, рыба, орехи, семена тыквы; но биодоступность из еды спорна: проще цитруллин.
