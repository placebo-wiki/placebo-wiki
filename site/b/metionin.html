Метаболизм

Метионин

Не доказано.

почти нет данных на людях
ДозаВсе цифры в пуле: для коров: 3.5-67.9 г/сут, оптимум 13.2-16.4 г/сут защищённого метионина
Пределв абстрактах не указан
Эффект черезСроки ответа изучались только у коров: 68-72 дня для защищённого метионина. Для человека не изучалось.
Кому нужноНи для кого по данным пула: все три мета-анализа выполнены на коровах, ни один: на людях.

Суть

Все три мета-анализа по метионину: про дойных коров, а не про людей; для человека как добавки данных в пуле нет.

Что говорят исследования

Рост белка молока у коровне доказано
Белок молока растёт, удой нетне доказано
Эффект добавки у людей не исследованне доказано

Форма важна

Выбирать нечего: подтверждённых доз для человека нет, а указанные в мета-анализах граммы рассчитаны на коров с обратным перегоном..

Мифы

«Мета-анализ доказывает пользу»: все три проведены на метионине для дойных коров, переносить их на человека нельзя.

«Улучшает силу»: в пуле нет ни одной работы на людях.

Осторожно

Переносить дозы и эффекты с дойных коров на человека нельзя: эти животные используют метионин для синтеза белка молока.

С лекарствами

Нет данныхизвестных взаимодействий нет

Из еды

В abstract'ах пула пищевые источники для человека не обсуждаются: все три мета-анализа про кормление дойных коров.
