Шатавари

Зависит от условий. Есть данные: усиление лактации у кормящих матерей. При условиях: пищеварение, ЖКТ-комфорт.

мало испытаний
Доза250-500 мг экстракта 2 раза/сут, стандартизация по сапонинам
ПределФормального UL нет. Дозы до 1 г/сут считаются безопасными короткими курсами.
Эффект через3-7 дней для эффекта на лактацию; для адаптогенного эффекта: 2-4 недели.
Кому нужноКормящие матери с недостатком молока (есть РКИ). Женщины в менопаузе: данных мало, есть традиционное использование.

Суть

Классика аюрведы для женского здоровья. Основное применение: стимуляция лактации у кормящих матерей.

Что говорят исследования

Усиление лактации у кормящих матерейработает
Пищеварение, ЖКТ-комфортзависит от условий
Снижение тревожности, улучшение настроенияне доказано

Форма важна

Стандартизированный экстракт по сапонинам 20-40%.

Избегать порошков неизвестного происхождения..

Мифы

«Стимулирует женские гормоны у мужчин»: нет данных.

«Работает для фертильности у всех»: только ограниченные данные для конкретных групп.

Осторожно

Не рекомендуется при беременности без консультации врача.

При лактации возможен эффект на гормоны.

Проверить наличие исследований на людях: их мало.

С лекарствами

Нет данныхизвестных взаимодействий нет

Из еды

В пищу не употребляется: корень принимается как экстракт или отвар.
