Антиоксидант

Кверцетин

Работает. При условиях: ВО2max +1.9%, EP +0.7%.

есть хорошие испытания
Доза500-1000 мг/сут
ПределФормального UL не установлен: данных о токсичности нет.
Эффект черезЭффект на АД: курсовой, недели приёма; эргогенного «за раз» нет.
Кому нужноПовышенное САД как мягкое дополнение; гиперурикемия/подагра: есть данные; аллергия/ОРВИ: нет.

Суть

Флавоноид: умеренно снижает систолическое АД; на выносливость эффект тривиальный.

Что говорят исследования

ВО2max +1.9%, EP +0.7%; «trivial» для тренированных и нетренированных (n=288)зависит от условий
Аллергия/ОРВИ: не подтверждён у людейне доказано
САД −1.9–2.4 мм рт.ст.; ДАД только в (пре)гиперт. подгруппе −3.1не доказано

Форма важна

500–1000 мг/сут с пиперином (биодоступность).

При давлении: не вместо, а вместе с лечением..

Мифы

«Лечит аллергию»: стабилизация тучных клеток только в пробирке.

«Повышает выносливость»: ВО2max +1.9%, но «trivial» и для любителей (МА 2013).

Осторожно

Кверцетин: флавоноид из лука/яблок.

Для давления: мета-анализ PubMed показывает умеренное снижение.

Для кардиометаболических факторов: улучшение маркеров (umbrella review 37654199).

Для выносливости: есть данные PubMed.

Для гиперурикемии/подагры: есть данные PubMed.

Биодоступность низкая: нужны формы с усилителями (пиперин, фосфолипиды).

Доза: 500-1000 мг/день.

С лекарствами

Антикоагулянтыусиливает эффект
Циклоспоринможет повышать концентрацию

Из еды

Лук, яблоки, чай, каперсы; биодоступность низкая: рабочая доза из добавки.
