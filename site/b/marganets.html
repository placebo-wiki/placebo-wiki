Марганец

Не доказано.

почти нет данных на людях
Дозав абстрактах не указана
Пределв абстрактах не указан
Эффект черезНе изучалось: РКИ с приёмом марганца в пуле нет.
Кому нужноТолько при подтверждённом дефиците или при нутритивной поддержке. Ни в данных по спортивной работоспособности, ни по веганской диете дефицит марганца не выявлен.

Суть

Марганец: эссенциальный микроэлемент, но в SR по минералам для спорта прямо указано: релевантных работ по марганцу не найдено.

Что говорят исследования

Коррекция дефицита при нутритивной поддержкене доказано
Возможное влияние на выпадение волосне доказано
Эффект добавки не исследованне доказано

Форма важна

Добавки марганца не поддержаны ни одной работой на людях из пула.

При подозрении на дефицит: анализ, а не самостоятельный приём..

Мифы

«Марганец нужен всем спортсменам»: в SR по 128 работам исследований по марганцу не нашли.

«Улучшает рост волос»: в SR по алопеции марганец есть лишь в списке, в выводах его нет.

Осторожно

ESPEN отмечает потенциальную токсичность микронутриентов при избытке; данных о безопасных дозах марганца в пуле нет.

С лекарствами

Нет данныхизвестных взаимодействий нет

Крупы, орехи и чай; отдельных данных об источниках марганца в abstract'ах пула не приводится.
