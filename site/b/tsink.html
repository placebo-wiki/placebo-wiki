Иммунитет

Цинк

Зависит от условий. Есть данные: менструальная боль ниже. При условиях: когниция ТОЛЬКО при дефиците.

есть хорошие испытания
Доза15-30 мг
Предел40 мг/сут длительно; месяцы выше 50 мг: дефицит меди.
Эффект черезПри дефиците (вкус, кожа, заживление): 4-8 недель; «иммунитет» субъективно не ощущается.
Кому нужноВегетарианцы и веганы (фитаты), мало животного белка, дефицит по анализу.
Статья: Цинк
Подробнее простыми словами: для чего, как принимать, мифы, сочетания

Суть

Кофактор иммунитета, кожи и синтеза тестостерона; конкурирует с медью.

Что говорят исследования

Менструальная боль ниже (Hedges' g -1.54)работает
Когниция ТОЛЬКО при дефицитезависит от условий
Тестостерон выше только при дефиците цинказависит от условий
Простуда короче и мягче при приёме цинка (пастилки)не доказано

Форма важна

Пиколинат, цитрат, глюконат.

15-25 мг элементарного цинка.

«50 мг + медь» без показаний не брать..

Цинк пиколинат, капсулы. Пиколинат усваивается лучше оксида. Долгий приём больших доз сбивает медь.

Цинк бисглицинат, капсулы. Хелатная форма, мягкая для желудка. По пользе равна пиколинату.

Цинк ионный, жидкий. Жидкая форма; отдельных испытаний мало.

Мифы

«Вылечит простуду за день»: пастилки слегка сокращают длительность.

«Больше: больше тестостерона»: только при дефиците.

Осторожно

Эффект при ОРВИ: ТОЛЬКО если начать приём в первые 24 часа.

Леденцы/сироп (не таблетки).

Доза 75-100 мг/день.

Побочки: тошнота, металлический привкус. >40 мг/день длительно → дефицит меди.

Для детей в развивающихся странах при диарее: рекомендация WHO.

С лекарствами

Антибиотики (хинолоны, тетрациклины)снижает всасывание, раздельный приём 2-4 часа
Препараты медидлительный приём снижает медь

Из еды

Устрицы, говядина, тыквенные семечки, сыр.
