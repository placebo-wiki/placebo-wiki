Антиоксидант

Астаксантин

Зависит от условий. Есть данные: креатинкиназа ниже после тренировок. При условиях: созревание ооцитов выше.

мало испытаний
Доза4-12 мг/сут с жирами
ПределФормального UL не установлен: данных о токсичности нет.
Эффект черезКурсовой: кожа: 3-6 мг/сут за недели; маркеры восстановления: после нагрузок.
Кому нужноВосстановление после тренировок (мышечные ферменты вниз); фотостарение кожи; фертильность (созревание ооцитов): контекст.

Суть

Каротиноид: после нагрузки креатинкиназа ниже, кожа лучше; на VO2max и исходы ЭКО: нет.

Что говорят исследования

Креатинкиназа ниже после тренировок (SMD -0.45); работоспособность не растётработает
Созревание ооцитов выше (MD 8.40); исходы ЭКО/беременности не меняютсязависит от условий
Влажность и эластичность кожи выше (SMD 0.53 и 0.77); глубина морщин без измененийзависит от условий
Кожа/глаза: слабо-положительно, контекстне доказано

Форма важна

3-6 мг/сут для кожи, 4-12 мг/сут с жирами для восстановления.

Стандартизация по Haematococcus pluvialis..

Мифы

«Прокачает VO2max»: нет (24 РКИ), работает восстановление.

«Лечит бесплодие»: созревание ооцитов лучше, ЭКО без изменений.

Осторожно

Астаксантин: каротиноид из водорослей Haematococcus pluvialis.

Для кожи: систематический обзор PubMed показывает улучшение параметров.

Для фертильности: есть данные (39127677, 41714661).

Для спорта/восстановления: данные ограниченные.

Для печени: есть данные.

Данных по клиническим исходам мало: в основном биомаркеры.

Безопасен в дозах 4-12 мг/день.

С лекарствами

Антикоагулянтытеоретический риск

Из еды

Исходно микроводоросль; в еде (лосось, криль) концентрации малы: рабочие 3-6 мг из добавки.
