Психика

SAMe

Работает. При условиях: депрессия адъюнкт: малые МА, печёночные показатели лучше, НЯ редкие.

есть хорошие испытания
Доза400-800 мг/сут натощак
ПределФормального UL не установлен: данных о токсичности нет.
Эффект черезДепрессия: улучшение в первые недели; боль при артрозе: малый сдвиг к 1–3 мес.
Кому нужноВзрослые с депрессией (дополнение к терапии); при остеоартрозе: мягкое обезболивание; при патологии печени.

Суть

Донор метильных групп; помогает при депрессии (адъювант), боли при остеоартрозе и поддержке печени.

Что говорят исследования

Депрессия адъюнкт: малые МАзависит от условий
Печёночные показатели лучше, НЯ редкие (1000–1200 мг/д; SR 15 статей)зависит от условий
Боль: SMD −0.17, ~0.4 см VAS; функция без эффекта (4 РКИ, 656)не доказано

Форма важна

Кишечнорастворимые формы, 400–800 мг/д натощак.

При депрессии/биполярке: только с врачом. Дорого..

Мифы

«Мгновенно поднимает настроение»: при большой депрессии эффект отсрочен.

«Безобиден при биполярке»: риск мании, только с врачом.

Осторожно

SAMe (S-аденозилметионин): универсальный донор метильных групп.

Для депрессии: эффективность сравнима с СИОЗС в РКИ.

Для остеоартрита: Cochrane-обзор PubMed подтверждает обезболивающий эффект.

Для печени: есть данные.

Для биполярного расстройства: ОСТОРОЖНО (риск мании).

Высокая цена, низкая стабильность: нужны кишечнорастворимые формы.

Доза: 400-1600 мг/день.

С лекарствами

Антидепрессанты SSRI/MAOсеротониновый синдром

Из еды

Из еды напрямую не набрать: синтезируется организмом из метионина (яйца, рыба, бобовые).
