Суть

Лейцин/изолейцин/валин: спорт-эффекта при достатке белка нет; ниша: печёночная энцефалопатия.

Что говорят исследования

Печёночная энцефалопатия: меньше симптомов (Cochrane, 827 чел.); на смертность нетзависит от условий
При достатке белка эффекта нетне доказано

Форма важна

Брать добавку только под цирроз с энцефалопатией.

Для спорта бессмысленно: белок/протеин эффективнее..

BCAA, порошок. Если белка в еде хватает, BCAA ничего не добавляют.

Мифы

«Качают мышцы без еды»: при достатке белка эффекта нет.

«Лечат печень»: только при энцефалопатии на циррозе, на смертность не влияют.

Осторожно

BCAA (лейцин/изолейцин/валин).

Для печеночной энцефалопатии при циррозе: 4 Cochrane-обзора показывают эффективность.

Для спорта: мета-анализы противоречивы: многие показывают отсутствие клинически значимого эффекта.

Для саркопении при циррозе: есть данные.

Для онкологии/операций: данные ограниченные.

С лекарствами

Леводопаконкурируют за всасывание

Из еды

Яйца, мясо, молоко, соя: весь белок содержит BCAA: проще есть белок, чем добавку.
