Спорт

L-цитруллин

Зависит от условий. При условиях: преэклампсия: для цитруллина данных нет.

есть хорошие испытания
Доза6-8 г малата за 60 мин до нагрузки
ПределФормального UL не установлен: данных о токсичности нет.
Эффект черезОстрое действие при приёме за 60 мин до нагрузки; накопительного эффекта нет.
Кому нужноСпортсмены на интенсивных нагрузках (цитруллин-малат 6–8 г); при преэклампсии пользы не доказано.

Суть

Прекурсор аргинина и NO: поднимает аргинин в плазме; спортивный эффект малый и не во всех РКИ; давления не снижает.

Что говорят исследования

Пампинг и нагрузки средней интенсивности: вазодилатация непостоянна, на выносливость эффекта не найдено; в силовых нагрузках малый эффект лишь в части РКИзависит от условий
Прямая вазодилатация при приёме непостоянна; эргогенный эффект в части РКИзависит от условий
Преэклампсия: для цитруллина данных нет (1 РКИ); у аргинина RR 0.52зависит от условий

Форма важна

Цитруллин-малат 6–8 г за 60 мин до нагрузки.

Биодоступнее аргинина, не метаболизируется в ЖКТ..

Цитруллин малат, порошок. Малат: соль с яблочной кислотой; дозу считают по цитруллину.

Мифы

«Снижает давление»: МА 2018 без эффекта на АД.

«Лечит преэклампсию»: данные есть у аргинина (RR 0.52), цитруллин: 1 РКИ без эффекта.

Осторожно

L-цитруллин: прекурсор аргинина и оксида азота (NO).

Эффективнее самого аргинина (не метаболизируется в ЖКТ, поднимает уровень аргинина лучше).

Для давления: мета-анализы показывают умеренное снижение.

Для спорта: улучшение производительности и восстановления.

Для эректильной функции: есть данные.

Для преэклампсии: есть данные.

Доза: 3-6 г/день.

Безопасен.

С лекарствами

Антигипертензивныеможет усиливать эффект
Нитратыусиливает вазодилатацию

Из еды

Вода из арбуза: богатый источник; для спортивной дозы проще добавка (6–8 г малата).
