Кордицепс

Зависит от условий.

есть хорошие испытания
Доза1-3 г/сут
ПределФормального UL не установлен: данных о токсичности нет.
Эффект черезКурсовой: в ходе терапии ХБП маркеры лучше; после трансплантации эффект к 6-12 мес.
Кому нужноХБП без диализа (адъювант, с врачом); реципиенты почечного трансплантата (не вместо иммуносупрессии); спорт не обоснован.

Суть

Гриб ТКМ: при ХБП снижение креатинина/протеинурии не подтверждено: качество РКИ слабое, окончательных выводов Cochrane-обзор не делает; после трансплантации лучше метаболизм, но нужны более качественные данные.

Что говорят исследования

Отторжение = азатиоприн, но нефротоксичность и метаболизм лучше (2017)зависит от условий
VO2: слабо у пожилых, у спортсменов нетне доказано
ХБП: креатинин −61 мкмоль/л, клиренс +9.2; качество РКИ слабоене доказано

Форма важна

1-3 г/сут стандартизированного гриба, с проверкой качества.

При ХБП/трансплантации: только с врачом..

Мифы

«Спортивный эргогеник»: РКИ по выносливости единичные, не систематизированы.

«Вылечит почки сам»: только адъювант, качество РКИ слабое.

Осторожно

Кордицепс (Cordyceps sinensis): гриб из традиционной китайской медицины.

Для ХБП: Cochrane-обзор PubMed видит возможное улучшение маркеров почек как адъюванта, но окончательных выводов не делает из-за низкого качества доказательств (риск систематической ошибки высокий в 4 РКИ и неясный в 18); свежий мета-анализ 2024 PubMed по дисфункции почек оптимистичнее, эффективность остаётся предметом дискуссии, обзоры расходятся.

Для реципиентов трансплантата почки: малые исследования с неясным риском систематической ошибки, результаты следует трактовать с осторожностью PubMed.

Для выносливости: данные ограниченные (отдельные РКИ, не систематизированы).

Для лёгочных заболеваний: данные ограниченные.

Дорогой препарат, часто подделывают.
