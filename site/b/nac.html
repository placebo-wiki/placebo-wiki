Антиоксидант

NAC

Работает. Доказано: меньше обострений ХОБЛ при 600 мг/день и ниже.

есть хорошие испытания
Доза600-1200 мг
ПределФормального UL не установлен: данных о токсичности нет.
Эффект черезМгновенного эффекта нет: при ХОБЛ обострения реже на дистанции, NAC пьют курсами.
Кому нужноПри ХОБЛ с частыми обострениями; печёночная недостаточность (в т.ч. парацетамол); резистентный H. pylori.

Суть

Прекурсор глутатиона: главного антиоксиданта клетки: меньше обострений ХОБЛ, защита печени.

Что говорят исследования

Меньше обострений ХОБЛ при 600 мг/день и нижеработает
Адъюнкт в OCD/депрессии, антиоксидантный статусзависит от условий
Меньше риск трансплантации при парацетамоловой печёночной недостаточностизависит от условий
Выше эрадикация H. pylori в связке с антибиотикамине доказано

Форма важна

Любая L-форма NAC, 600–1200 мг/сут. Дорогие «спортивные» версии не нужны: обзоры по классической форме..

Мифы

«Антиоксидант = здоровье»: при сепсисе смертность не снизил (Cochrane).

«Выше доза: лучше»: при ХОБЛ >600 мг без пользы; работает до 600 мг.

Осторожно

N-ацетилцистеин: прекурсор глутатиона. 4 Cochrane-обзора в базе!

Для ХОБЛ: снижает частоту обострений.

Для острой печёночной недостаточности (не-парацетамол): Cochrane.

Для H. pylori (адъювант): Cochrane.

Для сепсиса: Cochrane.

Для психиатрии (ОКР, трихотилломания, биполярное): есть РКИ с положительными данными.

Доза: 600-1200 мг 2 раза/день.

Безопасен, побочки: GI.

С лекарствами

Нитроглицеринусиливает эффект, риск гипотензии
Активированный угольснижает всасывание

Из еды

Отдельного пищевого источника нет: NAC: производное цистеина; цистеин есть в мясе, яйцах, овсянке.
