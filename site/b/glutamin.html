Глутамин

Зависит от условий. При условиях: ранние РКИ: меньше инфекций.

мало испытаний
Доза5-10 г/сут
ПределФормального UL не установлен: данных о токсичности нет.
Эффект черезМгновенного эффекта нет; в клинике дни-недели, польза не подтвердилась в крупных РКИ.
Кому нужноТолько в клинике как условно-незаменимый при критических состояниях (по назначению); здоровым: не показан, пользы нет.

Суть

Условно-незаменимая аминокислота; в реанимации эффект спорен, для спорта/мышц данных с исходами нет.

Что говорят исследования

Ранние РКИ: меньше инфекций; 2 крупных РКИ пользу не подтвердили (Cochrane 2014)зависит от условий
Мышцы: не подтверждён; кишка/иммунитет: только в клиникене доказано
Недоношенные: разницы по инфекциям и набору веса нет (Cochrane 2001)не доказано

Форма важна

Не нужна здоровым людям при полноценном питании.

В клинике используйте препараты по назначению врача, не БАД..

Мифы

«Условно-незаменимая = всем»: в клинике польза спорна (2024 МА).

«Для мышц»: РКИ нет.

Осторожно

Для критических состояний (ОРИТ, ожоги): Cochrane показывает НЕЯСНЫЙ эффект: одни РКИ положительны, другие нет.

Для недоношенных: Cochrane не показал пользы.

Для спорта/иммунитета после нагрузок: нет систематических данных с клиническими исходами.

Перорально безопасен, но эффект сомнителен вне ОРИТ.

С лекарствами

Химиотерапияможет снижать токсичность (адъювант)

Из еды

Красное мясо, птица, рыба, молоко, йогурт, бобовые: главные источники; при обычном питании дефицита нет.
