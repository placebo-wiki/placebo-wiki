Cuivre: est-ce que ça marche et comment en prendre

Verdict : non prouvé. Le cuivre est un minéral nécessaire à l'organisme, mais le bénéfice du complément avec un taux normal n'est pas montré : la prise n'a de sens qu'en cas de carence confirmée par une analyse.

non prouvé une synthèse de 1 186 études

Ce que montrent les études

Dans une revue systématique sur le régime végétalien, aucune carence en cuivre n'a été trouvée, même chez les végans.

Le guide ESPEN note directement le manque d'études d'intervention sur les compléments de cuivre.

Ce qui n'est pas prouvé

On ne sait pas si le complément de cuivre aide en cas de carence latente sans analyse : il n'y a pas d'études séparées chez l'humain.

On ne sait pas si le cuivre aide en cas de chute de cheveux : dans la revue sur l'alopécie androgénétique, il est seulement mentionné dans la liste des micronutriments.

L'effet du complément de cuivre en dehors d'une carence n'est pas confirmé.

Mythes

Le mythe « le cuivre est nécessaire à tous » est faux : dans une revue systématique sur le régime végétalien, aucune carence en cuivre n'a été trouvée.

Le mythe « le cuivre améliore la pousse des cheveux » est faux : dans la revue sur l'alopécie androgénétique, les conclusions concernent les vitamines du groupe B, la vitamine D, le fer, le sélénium et le zinc, et le cuivre est simplement dans la liste.

Comment en prendre

La dose n'est pas indiquée dans les études disponibles, et les délais d'apparition de l'effet n'ont pas été étudiés : il n'y a pas d'essais randomisés séparés avec mesure des délais. La limite supérieure n'est pas indiquée dans les sources ; le guide ESPEN prévient séparément d'une toxicité possible des micronutriments en cas d'excès. En cas de suspicion de carence, il faut une analyse de sang, et non une prise de sa propre initiative.

Qui doit faire attention

Sans carence confirmée par une analyse, le complément n'est pas utile : dans l'alimentation habituelle, aucune carence en cuivre n'a été trouvée, même chez les végans.

En cas d'excès de micronutriments, une toxicité est possible, comme le prévient le guide ESPEN.

Avec les médicaments

Aucune interaction connue avec des médicaments.
