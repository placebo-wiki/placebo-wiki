Sélénium: est-ce que ça marche et comment en prendre

Verdict : ça dépend. Le sélénium réduit probablement les anticorps et la TSH, mais seulement chez les personnes atteintes de thyroïdite de Hashimoto, et pour les personnes saines avec un niveau normal, le complément n'est pas indiqué.

ça dépend une synthèse de 1 429 études

Ce que montrent les études

Chez les personnes atteintes de thyroïdite de Hashimoto, le sélénium réduit probablement les niveaux des anticorps TPOAb et TgAb et la TSH, c'est ce qu'a montré une méta-analyse de 2024.

Le sélénium réduit probablement le MDA quand il est pris sous forme de complément, c'est ce qu'a montré une méta-analyse de 2024.

Ce qui n'est pas prouvé

Le sélénium peut aider, mais seulement en cas de Hashimoto ou de déficit : chez les personnes saines avec un niveau normal, il n'y a pas d'effet.

Mythes

Le mythe « le sélénium est bon pour la thyroïde de tous » est faux : l'effet est montré dans le Hashimoto, pas chez tout le monde.

Le mythe « il faut en prendre au cas où » est faux : avec un niveau normal de sélénium, le bénéfice n'est pas montré.

Le mythe « toutes les formes se valent » est faux : les formes de sélénium n'ont pas été comparées dans les revues.

Comment en prendre

La dose exacte de sélénium dans les compléments n'est pas donnée dans les revues, la dose est à valider avec un médecin. La prise se justifie seulement en cas de déficit confirmé ou de maladie de Hashimoto ; avec un statut normal, le complément n'est pas indiqué. Dans le Hashimoto, la baisse des anticorps et de la TSH est décrite sur une cure de prise, les délais précis ne sont pas isolés dans la méta-analyse ; la durée se définit selon l'évolution des anticorps et de la TSH sous contrôle médical. La limite supérieure n'est pas établie : les doses élevées donnent un risque de sélénose.

Qui doit faire attention

Pour les personnes saines avec un niveau normal de sélénium, le complément n'est pas indiqué.

Tout le monde doit garder en tête que le sélénium est toxique en excès : une sélénose est possible, donc la dose doit être validée avec un médecin.

Avec les médicaments

Statines : le sélénium peut réduire leur effet, mais ces données sont débattues.
