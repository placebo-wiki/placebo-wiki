Ginseng: est-ce que ça marche et comment en prendre

Verdict : ça marche, mais pas dans tous les cas. Le ginseng américain aide probablement contre la fatigue pendant la thérapie du cancer (recommandation ASCO 2024). La condition principale : chez les personnes saines, l'effet est faible, et pour la mémoire, les données ne sont pas confirmées.

ça marche une synthèse de 759 études

Ce que montrent les études

Le ginseng américain aide probablement contre la fatigue pendant la thérapie du cancer : c'est un soutien temporaire pendant le traitement, recommandation ASCO 2024.

La mise à jour 2024 des recommandations ASCO sur la fatigue chez l'adulte après un cancer examine le ginseng américain.

Ce qui n'est pas prouvé

On ne sait pas si le ginseng aide la mémoire : dans une méta-analyse, l'amélioration de la mémoire était significative (SMD 0.19, 0.33 à doses élevées), mais le niveau de cet effet dans la base : non confirmé.

Le ginseng peut aider, mais seulement comme usage historique, à mieux supporter les charges : la consommation d'oxygène n'augmente pas pour autant, et les confirmations solides sont rares.

Mythes

Mythe : le ginseng améliore toute la pensée. Pour la mémoire, les données sont contradictoires : dans la méta-analyse, l'effet était significatif, mais dans l'ensemble il n'est pas confirmé, et l'attention et les fonctions exécutives ne changent pas.

Mythe : tous les ginsengs se valent. La fatigue a été étudiée précisément avec le ginseng américain.

Mythe : les adaptogènes sont bons pour tout le monde. Chez les personnes saines, les données sont faibles.

Comment en prendre

La dose exacte n'est pas donnée dans les résumés : dans la méta-analyse de 2024, des préparations de ginseng étaient utilisées, les doses élevées donnent un effet plus grand sur la mémoire (SMD 0.33). La limite supérieure n'est pas établie. On l'utilise en cure selon les protocoles des essais randomisés, en général des semaines ou des mois ; contre la fatigue pendant la thérapie du cancer, selon le protocole ASCO. Pour la mémoire, on utilise le ginseng asiatique (Panax ginseng), pour la fatigue pendant la thérapie du cancer : le ginseng américain (Panax quinquefolius) ; on choisit des extraits standardisés, les doses selon les protocoles des études.

Qui doit faire attention

En cas de cancer, la prise de ginseng se valide avec l'oncologue.

Pour les personnes saines, le complément est presque inutile : l'effet chez les personnes saines est faible, et les données de sécurité y sont limitées.

Avec les médicaments

Anticoagulants : le ginseng peut influer sur la coagulation du sang.

Insuline et médicaments hypoglycémiants : le ginseng renforce l'effet hypoglycémique, c'est-à-dire la baisse du sucre dans le sang.

Caféine : le ginseng renforce la stimulation.
