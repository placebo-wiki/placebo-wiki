MCP для агентов

Подключите базу к Claude, Cursor или своему агенту: он будет отвечать о БАДах с уровнем доказанности и ссылками на исследования, а не выдумывать.

Инструменты

  • search(query): найти БАД по названию или синониму, на русском или английском.
  • get_supplement(name): полная карточка: эффекты с уровнями, доза, верхний предел, формы, мифы, взаимодействия, источники (PMID, DOI).
  • by_goal(goal): что помогает для цели (сон, либидо, стресс и другие), самое надёжное первым.
  • list_goals(): список целей.

Подключение (Claude Code)

claude mcp add bady -- uv run --script /путь/к/placebo-wiki/mcp/server.py

Нужен uv; зависимости он поставит сам.
