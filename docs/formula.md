# Формула статьи

Нейросеть пишет статью только по этим правилам. Правила 1-6 проверяет программа `data/seo/verify.py`; статья, которая их нарушает, не публикуется.

## 1. Только из карточки
Статья строится из карточки вещества в базе (вердикт, эффекты с уровнями, доза, верхний предел, формы, мифы, взаимодействия, источники). Нейросеть не добавляет фактов от себя. Каждое число в статье есть в карточке.

## 2. Сила слова = надёжность данных
По стандарту GRADE для формулировок выводов (Santesso и др., 2020, doi:10.1016/j.jclinepi.2019.10.014): чем надёжнее данные, тем сильнее глагол.

| Уровень эффекта в базе | Надёжность | Как писать |
|---|---|---|
| работает, оценка A | высокая | «X снижает…», «X помогает…» |
| работает, оценка B | средняя | «X, вероятно, снижает…» |
| зависит | низкая или только для части людей | «X может помочь, но только …» (при нехватке, у пожилых и т.п.) |
| не подтверждено | очень низкая | «Неизвестно, помогает ли X…», «На людях не доказано…» |

Слово сильнее уровня («доказано» при уровне «зависит») запрещено.

## 3. Запретные слова
лечит, излечивает, гарантирует, гарантированно, чудо, чудодейственный, детокс, выводит шлаки, очищает организм, без побочных, абсолютно безопасен, всем нужен, обязательно пить, 100%, мгновенно, навсегда, лучший.

## 4. Кому и когда
Если эффект только при нехватке вещества, у определённых людей или в определённой дозе, это сказано в том же предложении. Опыты на животных и клетках не выдаются за эффект у людей.

## 5. Обязательные части
1. Короткий ответ в первых двух строках (вердикт и главное условие).
2. Разбор по вопросу статьи.
3. Доза из испытаний и верхний предел, если есть в карточке.
4. Источники: ссылки на исследования из карточки.
5. Дата обновления.
6. «Не является лекарственным средством. Перед приёмом проконсультируйтесь с врачом.»

## 6. Язык
Простые слова, без терминов без пояснения; без длинного тире.

## 7. Чего нет в формуле и что проверяет человек
Программа ловит числа, слова и пропуски, но не неверный смысл. Выборочно статьи читает человек.
